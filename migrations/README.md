# 데이터베이스 마이그레이션

실서버 배포 시 필요한 DB 마이그레이션 스크립트

## add_resigned_users.py

**목적:** 기존 퇴사자 4명을 users 테이블에 추가하고 퇴사 처리

**퇴사자 목록:**
- 심장원
- 아이티
- 이근혁
- 김단이

이 4명은 퇴사했지만 프로젝트 테이블에 담당했던 공사 히스토리가 남아있어서,
담당자 뱃지에 "(퇴사)" 표시를 위해 users 테이블에 등록이 필요합니다.

### 실행 방법

```bash
# 프로젝트 루트에서
python migrations/add_resigned_users.py
```

### 주의사항

- 이미 실행했다면 다시 실행해도 안전합니다 (중복 체크)
- 퇴사 처리된 사용자는 로그인할 수 없습니다
- users 테이블에 등록되어야 담당자 뱃지에 "(퇴사)" 표시됩니다

## 실서버 배포 체크리스트

```
1. [ ] git pull (최신 코드 가져오기)
2. [ ] 서버 재시작 (DB 스키마 자동 마이그레이션)
3. [ ] python migrations/add_resigned_users.py 실행
4. [ ] 브라우저에서 동작 확인
     - 메인 테이블 담당자 열에서 "(퇴사)" 뱃지 확인
     - 사용자 관리 모달에서 퇴사자 상태 확인
```
