- **프로젝트 편집 시 자동 알림 재도입** — 원본 공사 확정 카드 최신 스냅샷으로 갱신 + 스레드에 `[프로젝트코드 데이터 수정 알림]` 히스토리 답글
- **공사 확정 카드에 폴더 경로 라인 자동 추가** (AL열 값)
- **채팅 진행 중 리드 재문의 top-level 알림** (스레드 리플라이만으론 알림 안 뜨는 문제 회피)
- **고아 리드 감지·재발송 안전망** (5분 주기 스캔)

### 버그 수정
- **PUT 편집 API 500 에러** — range `A:AO → A:AP` (`_version` 시프트 미반영)
- **주소 정규화**: 카카오 REGION 응답 skip → 실제 도로명 우선 매칭
- **홈페이지 리드 지번 표기 자동 제거** (`(가산동, 이앤씨드림타워7차)` 형태 포함)
- **인입 카드 방문 주소 개행 → 공백 flatten** (blockquote 구조 깨짐 방지)
- **담당자 매핑 추가**: 강정권 `-JK`, 이상덕 `-SD` (Python·JS·JSON·시트 SWITCH 수식 다 필요)

### 환경 변화
- `SLACK_INVOICE_CHANNEL_ID` 신규 (`#영업_관리` 채널 ID)
- `PHONE_WORKFLOW_SYNC_ENABLED=false` 유지 (슬랙 도입 전 수동 입력 카드 방지)
- Scheduled Task `Restart-ITGFlask` 등록 — UAC 없이 서비스 재시작 가능

## 🐛 자주 마주치는 이슈

### Flask 서비스가 안 뜸
```powershell
Restart-Service ITGFlask
Get-Content dashboard\logs\itglobal_dashboard_error.log -Tail 50
```
`.env` 로드 실패, credentials.json 경로 오류, 포트 5000 충돌 순으로 확인.

### Slack 봇 응답 없음
1. `SLACK_*_TOKEN`, `SLACK_*_SIGNING_SECRET` 유효한지
2. Slack 앱 대시보드의 Event Subscription URL이 `https://pm.itg-aircon.com/slack/events`인지
3. Flask 로그에 `[SLACK/*봇] 초기화 완료 ✅` 있는지

### 시트에 데이터 안 들어감
1. 서비스 계정이 시트에 편집자로 공유됐는지
2. 시트 이름·탭 이름이 `.env`의 `GOOGLE_SHEET_NAME`, `ONLINE_LEADS_SHEET_NAME`과 일치하는지
3. `append_row`가 쓰는 범위(현재 `A:AP`)가 실제 컬럼 수와 일치하는지 — 컬럼 추가 시 `dashboard/utils/google_sheets.py:797` 확인

### 폴더 링크 클릭해도 안 열림 (사용자 문의)
- 사용자 PC에 `itgfolder://` 프로토콜 등록됐는지 확인 → [docs/employee-deployment/itgfolder-install.md](../docs/employee-deployment/itgfolder-install.md)
- Google Drive Desktop 설치 및 G: 마운트 확인
