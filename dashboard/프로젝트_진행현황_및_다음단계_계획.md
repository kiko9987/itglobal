## 🎯 Phase 5: 통합 자동화 (2026-06 ~ 진행 중)

### 5-A. Slack 봇 통합 (완료)
- **4개 봇 분리**: 온라인 문의 알림봇 · 방문 일정 알림봇 · 공사 현황 알림봇 · 수금 관리 알림봇
- **단일 진입점**: `https://pm.itg-aircon.com/slack/events`
- **인터랙티브 모달**: 통합 상담 모달 (유선/방문/견적/드랍), 새 프로젝트 등록 모달 (`/공사확정`)
- **액션 카드**: 상담하기, 기존 lead 연결, 방문일 수정, 방문 완료, 방문 취소, 취소 되돌리기
- **/청소 슬래시**: 봇 메시지 일괄 삭제 (관리자 전용)

### 5-B. 리드 인입 파이프라인 (완료)
| 채널 | 처리 |
|---|---|
| 홈페이지 (아임웹) | Gmail API 폴링 → 파싱 → 시트 등록 → Slack 카드 |
| 카카오톡·채널톡 | 채널톡 Developer API webhook → 시트 등록 → 매니저 답변 forward |
| 전화 문의 | Slack 워크플로 폼 → 시트 등록 → sync 폴링 → 카드 |
| 당근마켓 | 별도 시트 → apscheduler 자동 sync → 메인 시트 → 카드 |
| 거래처/기타 방문 | `/방문` 슬래시 → 방문 List 등록 (시트 등록 X) |

**부가 로직**:
- 재문의 자동 감지 (주소 매칭 → 이전 이력 카드에 표시)
- 스팸 감지 가중치 시스템 (false positive 방지 + 짧은 광고 차단)
- 전화번호 정규화, 이메일/연락처 자동 매칭
- 24시간 이내 같은 번호 중복 등록 차단

### 5-C. 주소 정규화 (완료)
- **Kakao Local API** 통합 (verified 도로명/지번)
- **시설명·층·호 자동 부착** (verified 주소 뒤에)
- **패턴 보강**: 시설명/멀티라인/공백 옵션/약식 도로명

### 5-D. 방문·프로젝트 파이프라인 (완료)
- **방문 예정일 범위 지정**: datepicker 2개 (시작일 + 종료일)
- **현장 사진 자동 저장**: 방문 카드 thread에 사진 첨부 → Google Drive 폴더 자동 생성
  - 폴더명: `(담당자이니셜) 주소 YY.MM.DD`
  - 폴더 ID가 리드 시트 P열에 저장 → 신규 프로젝트 등록 시 자동 채움
- **리드 → 프로젝트 자동 연동**: `/공사확정` 모달의 "리드 불러오기" 검색 UI
- **프로젝트 시트 AO=Lead No 컬럼** 추가 (역참조)

### 5-E. 수금 관리 (완료)
- 공사 현황 시트 입금 메모 자동 감지 → 수금 알림봇 카드
- 미수금 상태별 필터

### 5-F. 인프라·운영 (완료)
- **NSSM 서비스 등록**: `ITGFlask`, Caddy 서비스
- **Docker Redis**: 컨테이너 + AOF+RDB 영속화
- **Caddy HTTPS**: Let's Encrypt 자동 갱신, DDNS
- **동시성 보호**: Redis SETNX 액션 락, 편집 락
- **SSL 인증서 자동 체크** (Flask 시작 시 + 폴링)
- **Sentry-lite**: 관리자 알림 통합 (transient 에러는 skip)

### 5-G. 문서 폴더 프로토콜 (완료)
- **itgfolder://** 커스텀 URL 프로토콜 — 각 직원 PC 탐색기에서 폴더 열기
- **배포 준비 완료**: `install-itg-folder.reg` + `open-itg-folder.vbs`
- Flask NSSM LocalSystem 세션 격리 이슈 → 클라이언트 프로토콜로 근본 해결

### 5-H. 세금계산서 발행 흐름 (완료, 2026-07-06)

## 🛠️ 기술 스택

**Backend**: Flask 2.0+, Python 3.9+, Bolt for Python (Slack)
**Frontend**: Bootstrap 5, DataTables, Vite (모듈 번들링)
**데이터**: Google Sheets (SoR), Redis (캐시·락·큐), SQLite (감사 로그)
**외부 API**: Google Sheets/Drive/Calendar/Gmail, Slack, 채널톡 Developer, Kakao Local
**배포**: NSSM (Windows 서비스), Caddy (HTTPS 리버스 프록시), Docker (Redis)
**테스트**: pytest
