# 한국어 문구 다듬기 (아이티글로벌)

목표: **뜻은 그대로, 사람이 쓴 것처럼, 과장 없이 사실만.** AI 탐지를 피하는 게 목적이 아니라, 읽는 사장님이 믿고 연락하게 만드는 게 목적이다.
(기준 틀: 위키백과 "AI 글쓰기 징후"를 바탕으로 한 Humanizer 스킬의 6분류를 한국어·우리 업종에 맞게 옮김. 2026-10-12)

## 작업 순서

1. **용도·매체·독자 파악** — 구글/네이버/당근 광고, 홈페이지·FAQ, 슬랙 공지, 고객 문자 중 무엇인지. 모르면 먼저 묻는다.
2. **AI 티 표시** — 아래 6가지 중 해당하는 곳을 강한 것부터 찾는다.
3. **고친 안 작성.**
4. **자기 점검** — ①6가지 패턴이 남았는지 ②원문의 사실·숫자가 그대로인지 ③아이티글로벌 표현 규칙 ④매체 글자 수.
5. **결과 보고** — 아래 "결과 형식"대로.

지킬 원칙:
- 원문에 없는 사실·숫자·혜택을 덧붙이지 않는다. 문장에 필요한 숫자·이름이 없으면 빈칸(○○)으로 두고 묻는다.
- "쓸 수 있는 사실" 밖의 주장은 근거를 확인하기 전까지 쓰지 않는다.
- 사용자가 직접 쓴 글을 샘플로 주면 그 말투(문장 길이·어미·자주 쓰는 단어)에 맞춘다.
- 파일을 고칠 때는 글만 고치고 코드·링크 주소·데이터는 건드리지 않는다.

## AI 티 나는 한국어 표현 6가지

### 1. 말하는 대신 연출하기
- "단순한 A가 아닌 B", "A를 넘어 B로", "그것이 바로 ~입니다", "~의 새로운 기준", "~의 시작"
- 질문으로 시작해 스스로 답하기("냉방비 고민이신가요?") — 한 번은 괜찮지만 반복하면 티가 난다
- "상상해 보세요", "이제는 ~할 때입니다"
- 고치기: 하고 싶은 말을 바로 한다. 예) "사무실 천장형 에어컨, 실측 후 견적 드립니다."

### 2. 규칙적인 리듬
- 장점·형용사를 세 개씩 묶기("빠르고, 깔끔하고, 합리적인")
- 같은 어미 반복("~합니다. ~합니다. ~합니다."), 문장 길이가 다 비슷함
- 문장마다 느낌표, 대구 남발
- 고치기: 장점은 실제 있는 것만, 개수는 내용대로. 문장 길이와 어미를 섞는다.

### 3. 부풀리기·빌린 권위
- 완벽한, 최고의, 혁신적인, 압도적인, 독보적인, 프리미엄, 솔루션, 새로운 경험·가치, 선사합니다, 경험해 보세요, 만족을 드립니다
- 근거 없는 "업계 1위", "최초", "유일", "고객 만족도 ○○%"
- 고치기: 구체적인 사실로 바꾼다(20년·1만 건 시공, 하자보증 2년).
- **최상급·1위·최초·유일 같은 표현은 표시광고법상 근거가 있어야 한다. 근거가 없으면 뺀다.**

### 4. 형식 남발
- 줄마다 이모지(✨🔥👉), 굵은 글씨·글머리표 과다, 해시태그 나열, 제목마다 대괄호·콜론
- 고치기: 매체 관행 안에서 최소로. 광고 제목·설명에는 이모지를 쓰지 않는다.

### 5. 대화·초안 찌꺼기, 번역투
- "물론입니다", "다음과 같이", "도움이 되셨길 바랍니다", "결론적으로", "요약하자면"
- 번역투: ~를 통해, ~에 있어서, ~함에 있어, ~되어지다, ~를 가지고 있다, ~하는 것이 가능합니다, ~할 수 있도록 도와드립니다, ~에 대해
- 괄호 덧붙임 남발
- 고치기: 짧은 우리말로. 예) "홈페이지를 통해 확인하는 것이 가능합니다" → "홈페이지에서 확인하세요."

### 6. 엉뚱한 독자
- 우리 고객은 사무실·상가·병원·학원·공장의 사장님·관리자와 건설사다. 감성 문구보다 일정·비용·책임 시공에 관심이 있다.
- 가정용 느낌 표현(방, 안방, 원룸, 이사, "우리 집")은 쓰지 않는다.
- 일반인 대상 글에 업계 용어(냉매, 배관 미터 수, 실외기 용량)를 설명 없이 쓰지 않는다.

## 아이티글로벌 표현 규칙
- **'업소용' 대신 '상업용'** (상업용 냉난방기, 상업용 스탠드). 단 광고 **검색 키워드**의 '업소용'은 고치지 않는다(고객이 실제로 검색하는 말).
- **상업 전용** — 가정용 설치는 하지 않는다. **판매·설치 전용** — A/S·단순 수리 문구 금지(약품 세척은 함).
- '추천' 대신 **'전문 업체'**.
- **공사 시간대 단어(새벽·야간·주말·휴무일 공사)는 쓰지 않는다** → "영업·업무·생산 일정에 맞춰 공사 일정을 협의합니다."
- 면허가 아니라 등록: **"기계설비공사 등록 업체"** ('면허' 표현 금지).
- 방문: "빠른 방문", "무료 실측·방문 견적". **당일 방문 약속 금지**(실제로는 다음 날~3일).
- 지역: 서울·경기·인천(수도권) 기본. 다른 지역을 "불가"라고 단정하지 않는다(대형 현장은 받음).

## 쓸 수 있는 사실 (광고 문구 팩트)
- OBS 출연 / 20년·1만 건 이상 시공 / LG·삼성·캐리어 인증 전문점 / 하자보증 2년 / 세금계산서·법인 거래 가능 / 무료 실측·방문 견적
- 취급: 상업용 냉난방기, 시스템에어컨, 상업용 대형 스탠드(30~40평형), 전열교환기·FCU·매립 덕트, 약품 세척
- **쓰면 안 되는 것**: "소상공인 1등급"(만료), 당일 방문, 근거 없는 최상급
- 이 밖의 숫자(가격·지원금·시공 기간·할인)는 사용자 확인 후에만 쓴다.
- 출처: 메모리 `project_google_ads_playbook`(1. 사업). 사실이 바뀌면 그 메모리와 이 목록을 함께 고친다.

## 매체별 확인
- **구글 반응형 검색 광고**: 제목 30자·설명 90자. 한글은 한 글자를 2칸으로 세므로 제목은 한글 약 15자, 설명은 약 45자.
- **네이버 파워링크**: 제목 15자, 설명 45자.
- 고친 뒤 글자 수를 반드시 세어 보고, 넘으면 표시한다. 최종 확인은 매체 화면에서.
- 슬랙 업데이트 공지는 메모리 `project_announcement_convention` 형식을 따른다.

## 결과 형식

```
[고친 문구]
(최종안)

[바꾼 이유]
- "단순한 제품이 아닌 새로운 경험" → 삭제: 연출형, 내용 없음
- "최고의 시공" → "20년·1만 건 시공": 근거 없는 최상급을 사실로

[확인 필요]
- (원문에 없어서 빈칸으로 둔 숫자·이름, 근거가 필요한 주장)
```

이 스킬은 표현을 다듬을 뿐 사실을 보증하지 않는다. 가격·지원 내용·시공 범위가 맞는지는 마지막에 사람이 확인한다.
