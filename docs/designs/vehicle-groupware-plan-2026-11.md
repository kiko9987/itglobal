# 차량 — U+커넥트를 그룹웨어로 옮기는 설계 (2026-11-22)

> 목표(부장님): 영업사원이 U+커넥트에 따로 들어가지 않아도(로그인할 때마다 문자 인증) 그룹웨어에서 모든 차량 기능을 쓴다.
> 근거: 11-22 U+커넥트 총괄관리자 화면 전수 확인(메뉴 30개, 내려받기 없이 화면만), Open API 연동 규격서 Ver1.2(9종 신청·승인 대기, 문의 No.625).
> 디자인 기준: impeccable(Operate 모드 — 익숙한 표·지도·탭, 기존 그룹웨어 틀 그대로), copy-polish-ko(화면 글), web-design-guidelines(만든 뒤 코드 점검).

## 1. 한 줄 결론

U+커넥트에서 **실제로 쓰는 것은 '위치·운행 기록·차량 상태' 세 가지뿐**이고, 비용·정비·사고·예약 화면은 모두 비어 있다(직접 입력하는 칸이라 아무도 안 씀).
위치·운행·상태는 Open API 로 받아 오고, 비용·정비는 우리 결재 기록에서 자동으로 채우고, 예약은 이미 만든 '차량 배정'이 대신한다.
그룹웨어 '차량' 메뉴는 **차량 배정 / 운행일지 / 차량 관리** 세 칸으로 충분하다.

## 2. U+커넥트 메뉴 전수표

| U+ 메뉴 | 지금 쓰나 | 그룹웨어로 가져오는 방법 | 그룹웨어 자리 |
|---|---|---|---|
| 대시보드 | 숫자 요약(오늘 운행 91km 등) | API 로 계산 | 각 화면 위 요약 숫자 |
| 운행 관제 › 실시간 차량 위치 | **씀** (지도, 30초마다) | API 차량 현위치 | 차량 배정 › 지금 위치 |
| 운행 관제 › 운행 이력/경로 | **씀** (11월 1,125건, 지번 주소까지, 급가속 등 횟수) | API 하루 경로 + 안전운전 | 운행일지 › 운행 기록(경로 지도) |
| 차량 관리 › 차량 등록/조회/설정 | 씀(11대) | API 차량 목록 + 우리 차량 목록 | 차량 관리 › 차량 |
| 차량 관리 › 차량상태 조회 | **씀** (전압·연료·누적 km, 11대 모두 양호) | API 차량 상태 | 차량 관리 › 차량 |
| 차량 관리 › 사고이력 | 비어 있음 | 우리가 입력 | 차량 관리 › 정비·사고 |
| 차량 관리 › 차량비용 리포트 | 비어 있음(0원) | 결재 기록 자동 + 입력 | 차량 관리 › 비용 |
| 차량 관리 › 정비비용·유류비·하이패스·과태료·보험료 | 모두 비어 있음 | 결재 기록 자동(자금집행·법인카드에 차량 번호 있는 건 약 125건) + 입력 | 차량 관리 › 비용 |
| (소모품 관리) | 우리 계정엔 안 열림 | 우리가 만듦(주기 km·개월) | 차량 관리 › 정비 |
| 운행 관리 › 운행일지(국세청) | **씀** (쏘렌토 등, 사용자 칸 '-') | API 로 운행 재구성 + 배정으로 사용자 채움 | 운행일지 › 운행기록부 |
| 운행 관리 › 차량 예약 관리 | 비어 있음(예약 0건) | 필요 없음 — 차량 배정이 대신 | 차량 배정 |
| 운행 관리 › 가동률 리포트 | 계산돼 나옴(평균 22%) | API 운행 시간으로 계산 | 운행일지 › 가동률 |
| 운행 관리 › 화물 운행이력 | 포터 3대 운행(232건) | 운행 기록에 포함 | 운행일지 › 운행 기록 |
| 운행 관리 › 배송/운송·이상 감지 알림 | 해당 없음(부가서비스) | 안 가져옴 | — |
| 거점 관리 › 거점·출입 알림 지역 | 본사 1곳만, 알림 0 | 현위치로 우리가 계산 | 알림(회사 출입) |
| 안전/경제운전 › 지수·통계 | 점수 나옴(스파크 43점 등) — **운전자 칸 '-'** | API 안전·경제운전 + 배정한 사람 | 운행일지 › 운전 습관(사람별) |
| 안전/경제운전 › 운전자 휴게시간 | 화물차 기록 있음 | API 운행 시간으로 계산 | 운행일지 › 운행 기록 |
| 안전/경제운전 › 관리(과속 알림) | 설정 안 함(기본 144km/h) | 우리 알림으로 | 알림 |
| 조직관리 (앱 가입 8명·관리자 4명·권한) | 계정 관리용 | 필요 없음 — 그룹웨어 로그인 | — |
| 고객지원·환경설정 | 문의·약관 | 필요 없음 | — |

**U+ 가 못 하는 것을 그룹웨어는 할 수 있다**: U+ 는 운전자를 모르니 '운전자별 안전운전 지수' 화면이 비어 있다. 그룹웨어는 차량 배정으로 그날 누가 탔는지 알므로 **사람별 운전 습관·운행기록부 사용자 칸**을 채울 수 있다.

## 3. Open API 로 되는 것과 안 되는 것

| 받을 수 있음(9종) | 만들 수 있는 화면 |
|---|---|
| 차량 현위치 | 실시간 위치 지도, 가까운 차 찾기, 회사 출입 알림 |
| 차량 경로(1분·하루, 5초마다 좌표) | 운행 경로 지도, 출발지·도착지 주소(카카오 좌표→주소) |
| 경제운전(사용 시작·끝, 주행 전·후 계기판 km, 거리) | **운행일지 한 줄 한 줄**(국세청 양식 칸 그대로) |
| 안전운전(급가속·급정지·과속 등 횟수, 최고 속도) | 사람별 운전 습관, 과속 알림 |
| 차량 상태(누적 km·연료·전압·타이어 공기압·공회전) | 차량 상태, 배터리 방전 위험·소모품 주기 알림 |
| 차량 목록·단말 목록·단말 상태 | 차량 목록 동기화, 단말 고장 알림 |

| 받을 수 없음 | 대신 |
|---|---|
| 정비비·유류비·하이패스·과태료·보험료 | 결재(자금집행·법인카드)에서 차량 번호로 자동 + 직접 입력 |
| 사고 이력 | 직접 입력 |
| U+ 화면의 운행일지 주소 | 하루 경로 좌표를 카카오 키(이미 있음)로 주소로 바꿈 |

## 4. 그룹웨어 '차량' 화면 구성

메뉴 세 칸, 각 칸 안은 위쪽 탭(지금 그룹웨어의 하위 메뉴 방식 그대로).

### 4-1. 차량 배정 (직원 모두 — 휴대폰 중심)
- **내일 배정** (만들어 둠): 왼쪽 사람(일정확정 팀)·오른쪽 차, 끌어 놓기·누르기, 확정하면 DM.
- **지금 위치** (새로): 지도에 11대, 차마다 '오늘 탄 사람·운행 중/정지·마지막 시각'. 위에 주소 칸 — 급한 방문 주소를 넣으면 가까운 차 순서와 [전화]·[슬랙]. 영업사원이 U+ 에 들어가던 가장 큰 이유(차 어디 있나)를 여기서 끝낸다.
- **내 차** (휴대폰에서 기본 화면): 오늘 내 차·같이 타는 사람·차 위치·이번 주 내 운행.

### 4-2. 운행일지 (경영지원 — 위치 기록이라 권한 제한)
- **운행 기록**: 날짜·차량을 고르면 운행이 한 줄씩(출발→도착 주소, 시각, km, 운전자). 줄을 누르면 오른쪽에 경로 지도와 급가속 등 횟수. U+ '운행 이력/경로'와 같은 구성, 운전자 칸이 채워진 것만 다름.
- **운행기록부**: 국세청 양식 칸 그대로(사용일자·부서·성명·주행 전/후·출퇴근용·일반업무용), 차량·기간 골라 엑셀로 내려받기. 파나메라·벤츠는 계기판 km 입력 칸.
- **운전 습관**: 사람별·차량별 안전·경제운전 점수, 위험 행동 횟수, 전국 평균과 비교.
- **가동률**: 차량별 하루 평균 운행 시간·가동률(차를 줄이거나 늘릴 때 근거).

### 4-3. 차량 관리 (경영지원)
- **차량**: 11대(+파나메라·벤츠·랜드로버) 표 — 차종·연료·누적 km·연료 잔량·배터리 전압·보험 만기·검사 만기·단말 상태. 점검 필요한 줄은 위로, 빨간 표시.
- **정비·소모품**: 차량별 정비 이력(결재에서 자동으로 들어온 줄 + 직접 추가), 소모품(엔진오일·타이어·브레이크패드 등) 교체 주기와 '교체할 때 됨'.
- **비용**: 월별·차량별 유류비·정비비·하이패스·과태료·보험료(결재 기록 기준), 차량 한 대당 연간 유지비.
- **보험·검사**: 증권 만기(공유 드라이브 증권 파일 이름에서 처음 채움)·검사 만기, 한 달 전 알림.

## 5. 알림(슬랙 DM)

| 알림 | 받는 사람 | 근거 |
|---|---|---|
| 내일 차량 배정 요청 / 배정 확정 | 승정 대리 / 탄 사람 | 만들어 둠 |
| 배정 없는 운행·주말·밤 운행 | 경영지원 | API 운행 + 배정 |
| 과속(기준 km/h) | 경영지원(+본인) | API 안전운전 |
| 보험·검사 만기 한 달 전, 소모품 교체 시기 | 경영지원 | 차량 관리 |
| 배터리 전압 낮음(방전 위험)·단말 신호 끊김 | 경영지원 | API 차량·단말 상태 |

## 6. 만드는 순서

| 단계 | 내용 | 조건 |
|---|---|---|
| 지금(API 없이) | 메뉴 세 칸으로 나누기, 차량 관리(차량 표·보험/검사 만기·정비 이력 결재 자동·비용), 파나메라·벤츠 km 입력 | 바로 가능 |
| API 승인 직후 | 운행 자동 가져오기(매일 새벽) → 운행 기록·운행기록부, 차량 상태, 지금 위치 지도·가까운 차 | Secure Key 문자 |
| 그다음 | 운전 습관(사람별)·가동률·알림 | 운행 기록 2~4주 쌓인 뒤 |

## 7. 화면 원칙(impeccable Operate)

- 새 꾸밈 없이 지금 그룹웨어 틀(왼쪽 영역·위쪽 탭·표·오른쪽 펼침창)과 같은 단추·표·배지만 쓴다. 지도는 화면 하나의 주인공일 때만 크게(지금 위치·운행 경로).
- 표는 '점검 필요'·'만기 임박'만 색, 나머지는 회색 글자. 빈 화면은 "무엇을 하면 채워지는지"를 적는다(예: "U+ 연동 승인 뒤 매일 새벽 자동으로 채워져요").
- 휴대폰: 차량 배정·지금 위치·내 차만 휴대폰 우선. 운행일지·차량 관리는 PC 우선(휴대폰은 읽기만).

## 8. 정해야 할 것

1. 영업사원이 U+ 에서 주로 무엇을 보는지(차 위치? 내 운행? 예약?) — 앱 가입자 8명. '지금 위치·내 차'를 그 기준으로 맞춘다.
2. 지도: 카카오 지도(그룹웨어 주소 등록한 JavaScript 키 필요 — 카카오 개발자 화면에서 부장님이 발급) 또는 무료 지도(OpenStreetMap, 키 없음·한국 지명 표기 약함).
3. 운행기록부 출퇴근/일반업무 나누는 규칙(회사↔집 운행을 출퇴근으로 볼지, 전부 업무로 둘지).
4. 과속 기준 속도, 밤 운행 기준 시각.
