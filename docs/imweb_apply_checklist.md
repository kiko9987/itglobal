# 홈페이지 SEO 적용 순서 (2026-11-15)

점검 결과를 실제로 반영하는 순서. 앞의 5개는 **설정만 바꾸면 되는 것**으로 다 합쳐 15분쯤이고,
뒤의 3개는 디자인 모드에서 글을 고치는 일이라 시간이 더 든다. 번호 순서대로 하면 서로 충돌하지 않는다.

관리자 화면 경로는 아임웹 공식 가이드(imweb.me/blog?idx=368) 기준이다. 화면에서 이름이 조금 다르면 알려 주시면 다시 찾겠다.

---

## 1. AI 검색 허용 켜기 — 제일 먼저, 1분

**지금 상태**: Claude-SearchBot · PerplexityBot · ChatGPT-User 가 우리 홈페이지에서 403(접근 거부)을 받는다.
Claude·Perplexity 답변에 우리 페이지가 인용될 수 없고, ChatGPT가 우리를 추천하려고 페이지를 열어볼 때도 실패한다.
ChatGPT 광고를 돌리는 중이라 이게 그냥 둘 일이 아니다.

**원인**: 아임웹에 **'AI 검색 허용(크롤링 허용)'** 옵션이 있고, 그게 꺼져 있어서 아임웹 서버가 막는 것이다.
(차단 페이지가 아임웹 CloudFront 에서 오고, 파일 날짜가 2026-08-28 이다. 우리가 넣은 robots.txt 는 전부 허용인데도 막힌다)

**방법**
1. 아임웹 관리자 → **[환경 설정] → [SEO 설정]**
2. **'AI 검색 허용'**(크롤링 허용) 옵션을 **켠다**.
3. 같은 화면에 **llms.txt 사용** 옵션이 있으면 그것도 켠다. 우리는 이미 /llms.txt 를 직접 넣어 두었으니,
   아임웹 자동 생성과 겹치면 어느 쪽이 나가는지 알려 주시면 맞추겠다.

**끝나면 알려 주세요.** 봇별로 다시 접근해 보고 403 이 풀렸는지 바로 확인해 드린다.

## 2. 페이지 7개 검색엔진 노출 끄기 — 5분

**이유**: 사이트맵 13개 중 7개가 쓰레기·옛 페이지인데 검색엔진에 제출되고 있다.

| 주소 | 실제 내용 |
|---|---|
| /37 | 테스트 게시판 '이름 없는 게시판' (글 2개: codes, test) |
| /48 | 빈 페이지 |
| /49 | 옛 세척 랜딩 |
| /50 | 옛 홈 랜딩 ('17년간 9,000건' 옛 문구) |
| /53 | 빈 페이지 (메뉴·푸터만) |
| /54 | 옛 세척 랜딩 ('에어컨 클리닝') |
| /contact-board | 열면 /login 으로 튕기는 로그인 전용 게시판 |

**방법**
1. **디자인 모드 → 왼쪽 상단 [메뉴]**
2. 해당 메뉴 옆 **'i'(설정) 클릭**
3. **검색엔진 노출 / 색인 관련 항목을 끈다.**

**⚠️ 페이지를 삭제하지 마세요.** 특히 **/50 은 메인 FAQ 게시판의 글 주소(/50/?idx=…)** 가 걸려 있어
삭제하면 FAQ 글이 깨진다. 노출만 끄면 아임웹이 noindex 를 붙이고 사이트맵에서도 자동으로 빠진다.

메뉴 목록에 /37·/48·/53 처럼 번호만 있는 페이지가 안 보이면, 숨은 메뉴일 수 있다. 그때는 알려 주시면 다시 찾겠다.

## 3. robots.txt 교체 — 2분 (2번을 한 뒤에)

**이유**: 지금 robots.txt 의 Disallow 절반이 거꾸로 걸려 있다.
`/35` `/home` `/introduce` 와 backup 페이지들은 **이미 noindex 가 걸려 있는데 robots 로도 막아 놔서**,
구글이 페이지를 못 읽고 그 안의 noindex 도 못 본다. 그래서 색인에서 빠지지 않는다.

**방법**: 지난번(10/5) robots.txt 를 넣었던 칸에 `docs/imweb_robots.txt` 내용을 그대로 붙인다.
(주석 `#` 줄까지 같이 붙여도 된다. 검색엔진은 무시한다)

2번보다 먼저 넣으면 그 7개가 잠깐 색인될 수 있으니 순서를 지킨다.

## 4. 스키마 블록 교체 — 3분

**이유**: Organization 구조화 데이터의 **로고 주소가 403으로 죽어 있다.**
10/19 에 아임웹 로고를 바꾸면서 예전 주소(`thumbnail/20250821/…`)가 사라진 것이다. 구글이 우리 로고를 못 가져간다.
주소·좌표·영업지역도 우리 블록에 없었다.

**방법**
1. 지난번 head 코드를 넣었던 칸(코드 삽입)을 연다.
2. `<!-- 구조화데이터 (Organization + VideoObject) -->` 아래의 **Organization `<script>` 한 덩어리만** 지우고,
   `docs/imweb_organization_schema.html` 의 `<script>` 부분을 붙인다.
3. **그 아래 VideoObject 주입 `<script>` 는 건드리지 않는다.** 그 안의 로고 주소도 같이 고쳐야 하니,
   `thumbnail/20250821/2b805c12024a3.png` 를 `upload/S2020040584513d33c8b3c/5ec59760c7ec1.png` 로 바꾼다.

**⚠️ 코드 칸을 통째로 교체하지 마세요.** GTM·픽셀·스타일이 같이 들어 있다.

## 5. 관리자 설정 두 가지 — 2분

1. **인스타그램 주소**: SNS 주소 칸에 `instagram.com/systemaircon_itg` 로 `https://` 없이 들어가 있다.
   아임웹이 자동으로 만드는 구조화 데이터에 그대로 쓰여 무효 값이 된다.
   → `https://www.instagram.com/systemaircon_itg/` 로 고친다.
2. **기본 도메인**: 사이트맵의 13개 주소가 모두 `itg-aircon.com`(www 없음)인데 실제로는 `www` 로 넘어간다.
   기본 도메인이 `www.itg-aircon.com` 으로 지정돼 있는지 확인한다.

## 여기까지 하면 설정 작업은 끝. 아래는 글을 고치는 일이다.

## 6. /event 한전 페이지 문구 — 10분

지금 페이지가 **끝난 사업을 모집 중처럼** 말하고 있다('아이티글로벌과 함께하세요').
문의가 와도 안 되는 이유를 설명해야 하니 가장 급한 문구다. 바꿀 제목·설명·본문은 `docs/imweb_page_meta.md` 에 있다.

## 7. 옛 숫자 '17년 이상 · 9,000+번' 지우기 — 15분

살아 있는 페이지 3곳 첫 화면에 그대로 있다: `/review` `/event` `/construction-case`.
지금 사실은 20년·1만 건이다. `/35` `/50` 에도 '2007 설립 17년차', '수상경력 40회' 가 남아 있다.
검색 스니펫과 AI 답변이 이 숫자를 인용할 수 있다.

## 8. 페이지별 제목·설명 — 15분

홈 말고 모든 페이지가 **옛 사이트 제목**('냉·난방기 | 시스템 에어컨 전문 | (주)아이티글로벌')으로 시작해
34자까지 길어지고 핵심 단어가 잘린다. `/cleaning` `/event` `/index` 설명은 홈과 글자까지 같다.
바꿀 값은 `docs/imweb_page_meta.md`.
경로: 디자인 모드 → [메뉴] → 메뉴 옆 'i' → 페이지 제목·페이지 설명.

## 따로 판단이 필요한 것

- **홈의 고객 후기 카드 3개가 `/35/?idx=…` 로 간다.** /35 는 robots 로 막혀 있고 noindex 라서
  **후기 글이 검색에 하나도 색인되지 않는다.** 게다가 /35 상단에 옛 홈 섹션이 남아 있어
  고객이 후기를 누르면 '2007 설립 17년차' 를 본다.
  → /35 의 옛 홈 섹션을 지우고 후기 게시판만 남긴 뒤 노출을 켜면 후기가 검색에 잡힌다. 이건 손이 좀 간다.
- **/review 와 /review1**: 메뉴는 /review 를 가리키는데 실제 후기 글(9쪽)은 /review1 에 있다.
  어느 쪽을 공식으로 할지 정하고 다른 쪽은 노출을 끈다.
- **H1 없는 페이지**: /review · /review1 · /contact-board · /event.
- **이미지**: 홈 이미지 21개가 모두 즉시 로드된다(lazy 0개). alt 빈 것 7개.
