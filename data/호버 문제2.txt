이제 CSS로 시도해볼 수 있는 마지막 방법을 제안해 드립니다. 이 방법은 충돌의 원인이 되는 스타일을 덮어쓰는
  대신, 모든 배경 스타일을 초기화하고 원하는 상태에만 색을 입히는 방식으로 접근합니다. 이것으로 해결되지
  않으면 자바스크립트 코드를 직접 수정하는 것 외에는 방법이 없습니다.


  해결 방법 (CSS 최종 시도)
  `css
  /*
    테이블 행 스타일 제어 (최종 시도)
    - 접근 방식: 모든 행의 배경을 투명하게 초기화 후, 각 상태에 필요한 색만 명시적으로 지정
  */

  / 1. 모든 행의 배경색을 기본적으로 투명하게 만들어 다른 스타일과의 충돌을 원천 차단 /
  .table-wrapper table.dataTable tbody tr > td {
      background-color: transparent !important;
  }

  / 2. 활성 행(.table-active)에만 오렌지색 배경 적용 (호버 상태 포함) /
  .table-wrapper table.dataTable tbody tr.table-active > td,
  .table-wrapper table.dataTable tbody tr.table-active:hover > td {
      background-color: #FFF3E0 !important; / 연한 오렌지색 /
      color: #37474F !important;
  }

  / 3. 비활성 행에 마우스를 올렸을 때만 회색 호버 효과 적용 /
  .table-wrapper table.dataTable tbody tr:not(.table-active):hover > td {
      background-color: #f5f5f5 !important; / 일반적인 호버 회색 /
  }
  `


  새로운 코드 설명
   1. 1번 규칙: 모든 테이블 칸(td)의 배경을 강제로 transparent(투명)로 만듭니다. 부트스트랩의 줄무늬 스타일,
      기본 호버 스타일 등 회색을 유발하는 모든 원인을 원천적으로 무력화시킵니다.
  이 세 가지 규칙의 조합으로 각 행의 상태(기본, 활성, 호버)가 서로 절대 간섭하지 않도록 명확하게
  분리했습니다.

  ### 적용 방법


   1. dashboard/src/css/main.css 파일의 기존 tr.table-active 관련 코드를 모두 삭제합니다.
  부디 이번에는 문제가 해결되기를 바랍니다.
