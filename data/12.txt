#### **2-2. Google Sheets API Rate Limiting 및 Retry 메커니즘**
**파일**: `dashboard/utils/google_sheets.py`

**문제점:**
- Google Sheets API 할당량 초과 시 저장/조회 실패
- 동시 사용자 증가 시 429 에러 빈발
- Quota: 300 req/min (전체), 60 req/user/min

**해결 방법:**
```python
# 1. Exponential Backoff with Jitter
MAX_RETRIES = 5
INITIAL_BACKOFF = 1  # 1초
MAX_BACKOFF = 32     # 최대 32초
RATE_LIMIT_ERROR_CODES = [429, 500, 503]

def _execute_with_retry(self, request, operation_name="API 호출"):
    for attempt in range(self.MAX_RETRIES):
        try:
            return request.execute()
        except HttpError as e:
            if e.resp.status in RATE_LIMIT_ERROR_CODES:
                if attempt < self.MAX_RETRIES - 1:
                    # Exponential backoff + Jitter (thundering herd 방지)
                    backoff_time = min(
                        INITIAL_BACKOFF * (2 ** attempt) + random.uniform(0, 1),
                        MAX_BACKOFF
                    )
                    logger.warning(f"[Rate Limit] {backoff_time:.2f}초 후 재시도")
                    time.sleep(backoff_time)
                    continue
            raise
```

**적용된 메서드:**
- `get_sheet_data()` - 프로젝트 목록 조회 (line 187-193)
- `get_sheet_metadata()` - 시트 메타데이터 조회 (line 299-300)
- `update_row()` - 프로젝트 업데이트 (line 499-505)
- `append_row()` - 신규 프로젝트 추가 (line 463-469)
- `update_row_background_color()` - 배경색 업데이트 (line 380-384)

**재시도 전략:**
| 시도 | 대기 시간 | 누적 시간 |
|------|-----------|-----------|
| 1차 | 1초 + jitter | ~1초 |
| 2차 | 2초 + jitter | ~3초 |
| 3차 | 4초 + jitter | ~7초 |
| 4차 | 8초 + jitter | ~15초 |
| 5차 | 16초 + jitter | ~31초 |

async saveAllChanges(projectCode) {
  // 1. 이미 저장 중이면 큐에 추가
  if (this.isSavingInProgress) {
    // 동일 프로젝트 중복 요청 제거
    this.saveQueue = this.saveQueue.filter(item => item.projectCode !== projectCode);

    return new Promise((resolve, reject) => {
      this.saveQueue.push({ projectCode, resolve, reject, timestamp: Date.now() });

      // 대기 중 피드백 표시
      const saveBtn = this.accordionContainer.querySelector('.unified-save-btn');
      if (saveBtn) {
        saveBtn.innerHTML = `<i class="fas fa-clock me-1"></i>대기 중 (${this.saveQueue.length})`;
      }
    });
  }

  // 2. 저장 실행
  this.isSavingInProgress = true;
  try {
    await this._executeSave(projectCode);
    this._processNextInQueue(); // 큐 처리
  } catch (error) {
    this.isSavingInProgress = false;
    throw error;
  }
}
