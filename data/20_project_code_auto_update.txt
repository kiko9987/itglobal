## 사용자 요청
"2851 프로젝트가 사업자가 글로벌이고 담당자가 강성환인데 왜 G2851-JW야?"

## Google Sheets 규칙
```
=IF($B2890="플렌트","P"&TEXT(ROW()-1,"0000"),
   IF($B2890="글로벌","G"&TEXT(ROW()-1,"0000"),
      IF($B2890="글로벌그룹","R"&TEXT(ROW()-1,"0000"),)))
&SWITCH($C2890,
   "박용구","-YG","박정우","-JW","강성환","-SH","박민우","-MW",
   "이근혁","-GH","김호중","-HJ","아이티","-IT","김단이","-DN",
   "권태훈","-TH","주영민","-YM","심장원","-SJW","빈승정","-SJ",
   "박민재","-MJ","조성헌","-JSH","황해승","-HS","강민석","-MS","")
```

## 기대 동작
- 사업자: 글로벌 → `G`
- 행번호: 2890 → `2890`
- 담당자: 강성환 → `-SH`
- **최종 코드: `G2890-SH`**

## 요구사항
1. 새 프로젝트 등록 시: 자동 생성
2. 아코디언 편집 시: 사업자/담당자 변경 시 실시간 재생성

## 2.1 백엔드: 프로젝트 코드 생성 유틸리티

**파일: `dashboard/utils/project_code_generator.py`**

### 함수 1: `generate_project_code(row_number, company, manager)`
Google Sheets 규칙과 100% 동일하게 프로젝트 코드 생성

```python
def generate_project_code(row_number, company, manager):
    # 1. 사업자 → Prefix
    company_prefix = {
        '플렌트': 'P',
        '글로벌': 'G',
        '글로벌그룹': 'R'
    }
    prefix = company_prefix.get(company, '')

    # 2. 행번호 4자리
    number_part = f"{row_number:04d}"

    # 3. 담당자 → Suffix
    manager_suffix = {
        '박용구': '-YG', '박정우': '-JW', '강성환': '-SH',
        '박민우': '-MW', '이근혁': '-GH', '김호중': '-HJ',
        '아이티': '-IT', '김단이': '-DN', '권태훈': '-TH',
        '주영민': '-YM', '심장원': '-SJW', '빈승정': '-SJ',
        '박민재': '-MJ', '조성헌': '-JSH', '황해승': '-HS',
        '강민석': '-MS'
    }
    suffix = manager_suffix.get(manager, '')

    # 4. 조합
    return f"{prefix}{number_part}{suffix}"
```

**예시:**
- `generate_project_code(2890, '글로벌', '강성환')` → `G2890-SH`
- `generate_project_code(1234, '플렌트', '박용구')` → `P1234-YG`
- `generate_project_code(5678, '글로벌그룹', '심장원')` → `R5678-SJW`

### 함수 2: `parse_project_code(project_code)`
프로젝트 코드 → 구성 요소 분해

```python
    'suffix': '-SH',

```

### 함수 3: `should_update_project_code(current_code, row_number, company, manager)`
프로젝트 코드 업데이트 필요 여부 확인

```python
should_update_project_code('G2851-JW', 2890, '글로벌', '강성환')
# True (담당자가 박정우→강성환으로 변경)

should_update_project_code('G2890-SH', 2890, '글로벌', '강성환')
# False (변경 없음)
```

### Line 490-514: 프로젝트 코드 자동 업데이트

```python
from dashboard.utils.project_code_generator import generate_project_code, should_update_project_code

# 현재 또는 새로운 사업자/담당자 값 가져오기
company = data.get('사업자') or current_values[field_to_index.get('사업자', 1)]
manager = data.get('담당자') or current_values[field_to_index.get('담당자', 2)]

# 최종 프로젝트 코드 추적
final_project_code = project_code

# 사업자 또는 담당자가 변경되었는지 확인
if should_update_project_code(project_code, row_number, company, manager):
    new_project_code = generate_project_code(row_number, company, manager)
    if new_project_code and new_project_code != project_code:
        logger.info(f"[PUT] 프로젝트 코드 자동 업데이트: {project_code} → {new_project_code}")

        # 1. 구글 시트 업데이트
        current_values[0] = new_project_code

        # 2. 감사 로그 기록
        field_changes.append({
            'field_name': '프로젝트 코드',
            'old_value': project_code,
            'new_value': new_project_code
        })

        # 3. 클라이언트 응답용
        data['프로젝트 코드'] = new_project_code
        final_project_code = new_project_code
```

```javascript
            fullRefresh: true,
```

**왜 전체 새로고침?**
- 프로젝트 코드가 변경되면 DataTable의 행 ID도 변경됨
- 아코디언의 모든 `data-project-code` 속성 업데이트 필요
- 감사 로그 등 프로젝트 코드 참조하는 모든 컴포넌트 동기화 필요

## 7.1 프로젝트 코드 변경 시 부분 업데이트
현재는 전체 새로고침(`fullRefresh`)하지만, 향후 개선 가능:

```javascript
// 부분 업데이트 - 행 ID만 변경
if (projectCodeChanged) {
    const row = dataTable.row(`#row-${result.old_project_code}`);
    row.id(`row-${finalProjectCode}`);  // ID 업데이트
    row.data(result.project).draw(false);  // 데이터 업데이트

    // 아코디언 유지
    this.currentProjectCode = finalProjectCode;
    this.reopenAccordion(finalProjectCode, result.project);
}
```

**장점:**
- 페이지 새로고침 없이 프로젝트 코드 변경
- 아코디언 열린 상태 유지
- 더 나은 사용자 경험

**단점:**
- DataTable row ID 변경 로직 복잡
- 모든 DOM 참조 업데이트 필요
- 테스트 복잡도 증가

## 7.3 일괄 프로젝트 코드 재생성
관리자 기능: 모든 프로젝트 코드를 규칙에 맞게 재생성

```python
@projects_bp.route('/api/admin/regenerate-codes', methods=['POST'])
@admin_required
def regenerate_all_codes():
    updated_count = 0
    for row_number, project in enumerate(projects, start=2):
        company = project['사업자']
        manager = project['담당자']
        new_code = generate_project_code(row_number, company, manager)
        if new_code != project['프로젝트 코드']:
            # 업데이트 로직
            updated_count += 1

    return jsonify({'updated': updated_count})
```
