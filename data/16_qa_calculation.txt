3. 계산 필드: 마진율 (Margin Rate)
================================================================================

### 3.1 계산 로직

✅ PASS | 기본 계산식
  - marginRate = (netProfit / totalAmount) * 100
  - netProfit = totalAmount - totalCost
  - 파일: dashboard/src/js/components/ProjectRowAccordion.js:2465

✅ PASS | 0 나눗셈 방지
  - if (totalAmount === 0) { marginRate = 0 }
  - NaN 방지

✅ PASS | Number.isFinite() 검증
  - if (!Number.isFinite(marginRate)) marginRate = 0

✅ PASS | 범위 제한
  - 상한: 1000% (10배 이익)
  - 하한: -1000% (10배 손실)
  - marginRate = Math.max(-1000, Math.min(1000, marginRate))

✅ PASS | 소수점 처리
  - toFixed(2) → 12.34%
  - 표시 형식: +12.34% (양수), -5.67% (음수)

### 3.2 엣지 케이스 테스트

✅ PASS | 정상 마진율
  - 입력: totalAmount=10000000, totalCost=7000000
  - netProfit = 3000000
  - marginRate = (3000000 / 10000000) * 100 = 30%
  - 결과: 30.00%

✅ PASS | 적자 (음수 마진)
  - 입력: totalAmount=10000000, totalCost=12000000
  - netProfit = -2000000
  - marginRate = (-2000000 / 10000000) * 100 = -20%
  - 결과: -20.00%

✅ PASS | 총액 0 (나눗셈 불가)
  - 입력: totalAmount=0, totalCost=1000000
  - 조건: totalAmount === 0
  - 결과: marginRate = 0%

✅ PASS | 극단적 이익 (1000% 초과)
  - 입력: totalAmount=1000000, totalCost=-9000000
  - netProfit = 10000000
  - 계산: (10000000 / 1000000) * 100 = 1000%
  - 제한: Math.min(1000, 1000) = 1000%
  - 결과: 1000.00%

✅ PASS | 극단적 손실 (-1000% 미만)
  - 입력: totalAmount=1000000, totalCost=11000000
  - netProfit = -10000000
  - 계산: (-10000000 / 1000000) * 100 = -1000%
  - 제한: Math.max(-1000, -1000) = -1000%
  - 결과: -1000.00%

✅ PASS | NaN 방지
  - 입력: totalAmount=NaN, totalCost=1000000
  - netProfit = NaN - 1000000 = NaN
  - marginRate = NaN
  - 검증: Number.isFinite(NaN) = false
  - 결과: marginRate = 0%

✅ PASS | 2월 30일
