실제 워크플로우 분석:

  1. 사용자: 아코디언 편집 모드 진입
  2. 사용자: 여러 필드 수정 (현장 주소, 공사 내용 등)
  3. 사용자: 메모 버튼 클릭 → 메모 작성 → "저장"
     └─ 백엔드: smart_invalidate("current_sheet_data") ✅
  4. 사용자: 아코디언 하단 "저장" 버튼 클릭 (전체 저장)
     └─ 백엔드: load_data(force_refresh=True) ✅
  5. 사용자: F5 새로고침
     └─ 백엔드: 캐시 없음 → Google Sheets 로드 ✅

  gemini가 놓친 부분:

  gemini는 다음 시나리오를 가정했습니다:
  메모 저장 → (편집 저장 없이) 바로 F5 → 캐시 문제?

  하지만 실제로는:
  메모 저장 → 편집 저장 (force_refresh) → F5 → 문제 없음 ✅

  심지어 "메모만 저장하고 편집 저장 안 하는" 엣지 케이스도:
  - 메모 저장 시: smart_invalidate("current_sheet_data")로 캐시 삭제
  - F5 새로고침 시: 캐시 없음 → load_data() → Google Sheets 로드
  - 결과: 여전히 최신 메모 표시 ✅
