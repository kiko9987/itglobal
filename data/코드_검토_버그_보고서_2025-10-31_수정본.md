### 1. Redis 연결 실패 시 앱 크래시 (Critical)

**위치**: `dashboard/utils/redis_client.py:152-155`

**문제점**:
```python
except (ConnectionError, TimeoutError, RedisError) as e:
    logger.critical(f"Redis 연결 실패: {e}")
    logger.critical("서비스를 시작할 수 없습니다. Redis 서버를 확인하세요.")
    sys.exit(1)  # 프로세스 종료 ← 문제!
```

**시나리오**:
1. 앱 시작 시 Redis 일시적 장애 (네트워크 지연, 재시작 중)
2. `sys.exit(1)` 호출 → 프로세스 종료
3. Gunicorn/Docker가 재시작 시도
4. Redis 여전히 불안정 → 무한 재시작 루프

**영향도**: 서비스 전체 중단 가능

**수정 제안**:
```python
# 옵션 1: Fallback 모드로 전환 (이미 부분 구현됨)
except (ConnectionError, TimeoutError, RedisError) as e:
    logger.error(f"Redis 연결 실패, Fallback 메모리 캐시로 전환: {e}")
    self._enable_fallback()
    # 앱은 계속 실행 (캐시 없이 또는 메모리 캐시 사용)

# 옵션 2: 재시도 후 Fallback
for attempt in range(3):
    try:
        self.redis.ping()
        break
    except Exception:
        if attempt == 2:
            self._enable_fallback()
        time.sleep(2 ** attempt)
```

**현재 상태**: `_enable_fallback()` 메서드는 이미 구현되어 있으나 (라인 95-100), `__init__`에서 `sys.exit(1)` 이전에 호출되지 않음

### 3. 날짜 파싱 에러 처리 미흡 (High)

**위치**: `dashboard/blueprints/projects.py:274-309`

**문제점**:
```python
def _process_date_columns(df):
    date_columns = ['공사 확정', '공사 시작', '공사 종료', '계약금 입금일',
                    '중도금 입금일', '잔금 입금일']

    for col in date_columns:
        if col in df.columns:
            df[col] = pd.to_datetime(df[col], errors='coerce')  # ← 조용히 실패
            df[col] = df[col].apply(lambda x:
                x.strftime('%Y-%m-%d') if pd.notna(x) and x is not pd.NaT else ''
            )
```

**문제 시나리오**:
1. 사용자가 "2025/13/45" 입력 (잘못된 날짜)
2. `pd.to_datetime(..., errors='coerce')` → `NaT` 반환
3. 최종적으로 빈 문자열 `''` 저장
4. **사용자는 에러 메시지를 보지 못하고 날짜가 사라짐**

**영향도**: 데이터 손실, 사용자 혼란

**수정 제안**:
```python
def _process_date_columns(df):
    """날짜 컬럼 처리 (검증 강화)"""
    date_columns = ['공사 확정', '공사 시작', '공사 종료', '계약금 입금일',
                    '중도금 입금일', '잔금 입금일']

    invalid_dates = []  # 잘못된 날짜 수집

    for col in date_columns:
        if col not in df.columns:
            continue

        for idx in df.index:
            value = df.at[idx, col]
            if pd.isna(value) or value == '':
                df.at[idx, col] = ''
                continue

            try:
                # 명시적 검증 (errors='raise')
                parsed_date = pd.to_datetime(value, errors='raise')
                df.at[idx, col] = parsed_date.strftime('%Y-%m-%d')
            except Exception:
                # 파싱 실패 시 기록
                invalid_dates.append({
                    'row': idx,
                    'column': col,
                    'value': value
                })
                df.at[idx, col] = ''  # 빈 문자열로 설정

    # 잘못된 날짜가 있으면 경고 로그
    if invalid_dates:
        logger.warning(f"잘못된 날짜 형식 발견 ({len(invalid_dates)}개): {invalid_dates[:5]}")
        # 필요시 사용자에게 알림 (API 응답에 포함)

    return df, invalid_dates  # 잘못된 날짜 목록 반환
```

**우선순위**: 1주일 내 수정 권장

**아키텍처**:
```
프론트엔드 → acquire_lock() → [편집] → heartbeat (30초마다) → release_lock()
             ↓                                                     ↓
          Redis TTL 5분                                       수동 해제
```
