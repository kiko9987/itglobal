## 1.2 문제점

❌ **담당자 정보 누락**
   - 아코디언 헤더에 담당자가 표시되지 않음
   - 기본정보 카드에는 있지만 헤더에는 없음

❌ **편집 불가능**
   - 프로젝트 코드: 읽기 전용
   - 현장주소: 읽기 전용
   - 공사내용: 읽기 전용
   - 담당자: 표시조차 안 됨

❌ **프로젝트 코드 편집 불가 (이건 정상)**
   - 프로젝트 코드는 자동 생성되므로 직접 편집하면 안 됨
   - 사업자/담당자 변경으로 간접적으로만 변경되어야 함

## 1.3 기본정보 카드에 있는 필드들 (Line 420-456)

```
✅ 사업자 (editable)
✅ 현장담당자 (editable)
✅ 도급구분 (editable)
✅ 연락처 (editable)
✅ 시공자 (editable)
✅ 이메일 (editable)
```

**주의:** "담당자"와 "현장담당자"는 다른 필드!
- **담당자** (Column C): 사내 영업 담당자 (예: 강성환, 박정우) → 프로젝트 코드 생성에 사용
- **현장 담당자** (Column W): 시공 현장 담당자 (고객사 담당자)

## 2.3 담당자 변경 시 프로젝트 코드 자동 업데이트

**시나리오:**
1. 사용자가 담당자를 "강성환" → "박정우"로 변경
2. 저장 버튼 클릭
3. 백엔드에서 프로젝트 코드 자동 재생성:
   - `G2890-SH` → `G2890-JW`
4. 응답:
   ```json
   {
     "success": true,
     "project_code": "G2890-JW",
     "old_project_code": "G2890-SH",
     "project": { ... }
   }
   ```
5. 프론트엔드: 페이지 새로고침 (프로젝트 코드 변경됨)

**프로젝트 코드 배지 실시간 미리보기 (선택 사항):**
```html
<!-- 담당자 변경 시 -->
<div class="project-code-badge readonly">
  <i class="fas fa-tag"></i> G2890-SH
  <span class="code-preview-hint">
    → G2890-JW <i class="fas fa-info-circle"
                   title="저장 시 프로젝트 코드가 자동으로 변경됩니다"></i>
  </span>
</div>
```

```javascript
/**
 * 헤더 필드 생성 (읽기/편집 모드 자동 전환)
 */
generateHeaderFields(projectCode, projectData, isEditMode = false) {
  const manager = projectData['담당자'] || '';
  const address = projectData['현장 주소'] || '주소 정보 없음';
  const content = projectData['공사 내용'] || '공사내용 없음';

  if (!isEditMode) {
    // 읽기 모드
    return `
      <div class="project-code-badge readonly">
        <i class="fas fa-tag me-2"></i>${projectCode}
      </div>
      <div class="project-manager-info">
        <i class="fas fa-user me-2"></i>${manager || '담당자 미지정'}
      </div>
      <div class="project-address-info" title="${address}">
        <i class="fas fa-map-marker-alt me-2"></i>${address}
      </div>
      <div class="project-content-info" title="${content}">
        <i class="fas fa-tools me-2"></i>${content}
      </div>
    `;
  } else {
    // 편집 모드
    const managerOptions = [
      '박용구', '박정우', '강성환', '박민우', '이근혁', '김호중',
      '아이티', '김단이', '권태훈', '주영민', '심장원', '빈승정',
      '박민재', '조성헌', '황해승', '강민석'
    ];

    return `
      <div class="project-code-badge readonly">
        <i class="fas fa-tag me-2"></i>${projectCode}
        <span class="code-preview-hint" id="code-preview-${projectCode}" style="display: none;"></span>
      </div>
      <div class="project-manager-info editable">
        <i class="fas fa-user me-2"></i>
        <select class="header-edit-select" data-field="담당자" data-original-value="${manager}">
          <option value="">담당자 선택</option>
          ${managerOptions.map(m => `
            <option value="${m}" ${m === manager ? 'selected' : ''}>${m}</option>
          `).join('')}
        </select>
      </div>
      <div class="project-address-info editable">
        <i class="fas fa-map-marker-alt me-2"></i>
        <input type="text" class="header-edit-input"
               data-field="현장 주소"
               data-original-value="${address}"
               value="${address}"
               placeholder="현장 주소를 입력하세요">
      </div>
      <div class="project-content-info editable">
        <i class="fas fa-tools me-2"></i>
        <input type="text" class="header-edit-input"
               data-field="공사 내용"
               data-original-value="${content}"
               value="${content}"
               placeholder="공사 내용을 입력하세요">
      </div>
    `;
  }
}
```

```javascript
/**
 * 통합 편집 모드 활성화
 */
enableUnifiedEditMode(projectCode) {
  console.log(`✏️ [통합 편집] 편집 모드 진입: ${projectCode}`);

  if (this.isUnifiedEditMode) {
    console.log('⚠️ [통합 편집] 이미 편집 모드입니다.');
    return;
  }

  this.isUnifiedEditMode = true;

  // 1. 헤더 필드를 편집 모드로 전환
  const headerContainer = document.getElementById(`header-${projectCode}`);
  if (headerContainer) {
    headerContainer.innerHTML = this.generateHeaderFields(projectCode, this.currentProject, true);
    headerContainer.classList.add('editing');

    // 담당자 변경 시 프로젝트 코드 미리보기
    const managerSelect = headerContainer.querySelector('[data-field="담당자"]');
    if (managerSelect) {
      managerSelect.addEventListener('change', (e) => {
        this.previewProjectCodeChange(projectCode, e.target.value);
      });
    }
  }

  // 2. 기존 카드들을 편집 모드로 전환
  const cardTypes = ['basic', 'construction', 'financial', 'collection', 'profit'];
  cardTypes.forEach(cardType => {
    const card = document.getElementById(`card-${cardType}-${projectCode}`);
    if (card) {
      card.classList.add('editing');
      card.querySelectorAll('.editable-value').forEach(field => {
        this.makeFieldEditable(field);
      });
    }
  });

  // 3. 버튼 전환
  this.toggleUnifiedEditButtons(projectCode, true);
}
```

## 4.4 프로젝트 코드 미리보기 (신규)

```javascript
/**
 * 담당자 변경 시 프로젝트 코드 미리보기
 */
previewProjectCodeChange(projectCode, newManager) {
  const company = this.currentProject['사업자'];
  const rowNumber = this.getProjectRowNumber(projectCode);

  // 프로젝트 코드 생성 (클라이언트 사이드 로직 - 백엔드와 동일)
  const companyPrefix = {
    '플렌트': 'P',
    '글로벌': 'G',
    '글로벌그룹': 'R'
  };

  const managerSuffix = {
    '박용구': '-YG', '박정우': '-JW', '강성환': '-SH', '박민우': '-MW',
    '이근혁': '-GH', '김호중': '-HJ', '아이티': '-IT', '김단이': '-DN',
    '권태훈': '-TH', '주영민': '-YM', '심장원': '-SJW', '빈승정': '-SJ',
    '박민재': '-MJ', '조성헌': '-JSH', '황해승': '-HS', '강민석': '-MS'
  };

  const prefix = companyPrefix[company] || '';
  const suffix = managerSuffix[newManager] || '';
  const newCode = `${prefix}${String(rowNumber).padStart(4, '0')}${suffix}`;

  // 미리보기 표시
  const previewElement = document.getElementById(`code-preview-${projectCode}`);
  if (previewElement && newCode !== projectCode) {
    previewElement.textContent = `→ ${newCode}`;
    previewElement.style.display = 'inline';
    previewElement.title = '저장 시 프로젝트 코드가 자동으로 변경됩니다';
  } else if (previewElement) {
    previewElement.style.display = 'none';
  }
}

/**
 * 프로젝트 행번호 가져오기 (DataTable에서 추출)
 */
getProjectRowNumber(projectCode) {
  // DataTable row index + 2 (헤더 행 제외, 1-based indexing)
  const row = this.dataTable.row(`#row-${projectCode}`);
  if (row) {
    return row.index() + 2;
  }
  return 0;
}
```

```javascript
/**
 * 모든 변경사항 수집
 */
collectAllChanges(projectCode) {
  const changes = {};

  // 1. 헤더 필드 변경사항 수집
  const headerContainer = document.getElementById(`header-${projectCode}`);
  if (headerContainer && headerContainer.classList.contains('editing')) {
    headerContainer.querySelectorAll('[data-field]').forEach(field => {
      const fieldName = field.dataset.field;
      const originalValue = field.dataset.originalValue || '';
      let newValue = '';

      if (field.tagName === 'SELECT') {
        newValue = field.value;
      } else if (field.tagName === 'INPUT') {
        newValue = field.value.trim();
      }

      // 변경된 경우에만 추가
      if (String(newValue) !== String(originalValue)) {
        changes[fieldName] = newValue;
        console.log(`🔄 [헤더 변경] ${fieldName}: "${originalValue}" → "${newValue}"`);
      }
    });
  }

  // 2. 기존 카드 필드 변경사항 수집 (기존 로직 유지)
  const cardTypes = ['basic', 'construction', 'financial', 'collection', 'profit'];
  cardTypes.forEach(cardType => {
    const card = document.getElementById(`card-${cardType}-${projectCode}`);
    if (card && card.classList.contains('editing')) {
      // ... 기존 로직
    }
  });

  return changes;
}
```

================================================================================
7. 주의사항
================================================================================

⚠️ **프로젝트 코드는 직접 편집 불가**
   - 프로젝트 코드는 자동 생성 규칙을 따라야 함
   - 사업자/담당자 변경으로만 간접적으로 변경 가능
   - 헤더에서는 항상 읽기 전용 (readonly)

⚠️ **담당자 변경 → 프로젝트 코드 자동 변경**
   - 담당자를 변경하면 프로젝트 코드도 자동 변경됨
   - 사용자에게 미리보기로 알려줘야 함
   - 저장 후 페이지 새로고침 필요 (fullRefresh: true)

⚠️ **"담당자" vs "현장 담당자"**
   - **담당자**: 사내 영업 담당자 (프로젝트 코드에 사용)
   - **현장 담당자**: 시공 현장 담당자 (고객사)
   - 두 필드는 완전히 다른 필드임!

⚠️ **헤더 필드 수집 순서**
   - `collectAllChanges()`에서 헤더 필드를 먼저 수집
   - 카드 필드와 병합
   - 중복 필드는 헤더 값 우선

⚠️ **빈 값 처리**
   - 현장주소/공사내용을 완전히 지우면 빈 문자열 저장
   - 읽기 모드에서는 "주소 정보 없음" / "공사내용 없음" 표시
   - 담당자는 빈 값 허용 안 함 (드롭다운 기본값 필요)
