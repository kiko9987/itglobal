 이제 남은 마지막 문제는 '마우스를 떼었을 때' 회색이 섞이는 현상입니다.

  ### 마지막 문제의 원인: 테이블 줄무늬(Striped) 스타일


  이 현상의 원인은 99% 부트스트랩의 `.table-striped` 기능 때문입니다.


  테이블의 행들이 횐색-회색-흰색-회색 순으로 줄무늬를 이루도록 하는 기능인데, 우리가 활성화한 오렌지색 행이
  마침 '회색 줄무늬' 차례일 경우, 우리가 지정한 오렌지색 배경 위에 반투명한 회색이 덧씌워져서 색이 섞여
  보이는 것입니다.

  ### 해결 방법 (최종 완성)


  이 문제를 해결하려면, 활성 행에 대해서는 '줄무늬용 회색'도 '우리가 원하는 오렌지색'으로 덮어쓰도록 CSS
  규칙을 수정해야 합니다.

  지난번에 드렸던 CSS 코드에서, 호버(`:hover`)가 없는 아래쪽 코드 블록만 다음 내용으로 교체해 주세요.


  `css
  /*
    활성 아코디언 행(.table-active) 기본 스타일 최종 수정
    - 기본 배경색을 오렌지색으로 지정
    - Bootstrap의 줄무늬(striped) 테이블 회색 배경이 섞이는 문제 해결
  */
  .table-wrapper table.dataTable tbody tr.table-active > td {
      --bs-table-bg: #FFF3E0;           / 부트스트랩 배경 변수 오버라이드 /
      --bs-table-striped-bg: #FFF3E0;   / 부트스트랩 줄무늬 배경 변수 오버라이드 (핵심!) /
      background-color: #FFF3E0 !important; / 최종 방어선 /
      color: #37474F !important;
  }
  `

  수정 후 `main.css` 파일의 최종 모습은 아래와 같아야 합니다.


  `css
  / main.css 파일 맨 아래 /

  /*
    활성 아코디언 행(.table-active) 호버 스타일 최종 수정
    DataTables와 Bootstrap의 모든 호버 효과를 강제로 덮어쓰기 위한 규칙
  */
  .table-wrapper table.dataTable tbody tr.table-active:hover > td {
      background-color: #FFF3E0 !important; / 오렌지 배경색 강제 유지 /
      box-shadow: none !important;           / 호버 시 나타날 수 있는 그림자 효과 제거 /
      outline: none !important;             / 호버 시 나타날 수 있는 외곽선 효과 제거 /
  }

  /*
    활성 아코디언 행(.table-active) 기본 스타일 최종 수정
    - 기본 배경색을 오렌지색으로 지정
    - Bootstrap의 줄무늬(striped) 테이블 회색 배경이 섞이는 문제 해결
  */
  .table-wrapper table.dataTable tbody tr.table-active > td {
      --bs-table-bg: #FFF3E0;           / 부트스트랩 배경 변수 오버라이드 /
      --bs-table-striped-bg: #FFF3E0;   / 부트스트랩 줄무늬 배경 변수 오버라이드 (핵심!) /
      background-color: #FFF3E0 !important; / 최종 방어선 /
      color: #37474F !important;
  }
  `

  ### 적용 방법


   1. dashboard/src/css/main.css 파일의 내용을 위 코드처럼 수정하고 저장합니다.
  이제 활성화된 행은 마우스를 올렸을 때나 떼었을 때나 모두, 다른 색의 간섭 없이 깨끗한 오렌지색 배경을
  유지할 것입니다.
