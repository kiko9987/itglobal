  [Critical] 문제 1: 인라인 업데이트 후 강제 새로고침

  위치: dashboard/blueprints/projects.py:816

  # 구글 시트 업데이트
  update_result = manager.update_row(sheet_id, row_number, current_values)

  # 캐시 무효화 (포괄적)
  invalidate_project_cache(project_code)

  # 로컬 데이터 새로고침 (강제) ⚠️ 여기가 문제!
  projects_df = load_data(force_refresh=True)

  문제점:
  - 캐시를 무효화한 직후 바로 load_data(force_refresh=True) 호출
  - 전체 구글 시트 데이터를 API로 다시 로드 (모든 프로젝트)
  - 단 하나의 프로젝트 수정에도 전체 데이터 강제 새로고침

  영향도:
  - 프로젝트 100개 시트 → 매번 전체 데이터 로드
  - 불필요한 Google Sheets API 호출
  - 응답 시간 증가

  개선 방안:
  # ❌ 현재 (강제 새로고침)
  projects_df = load_data(force_refresh=True)

  # ✅ 개선안 (캐시 무효화만)
  invalidate_project_cache(project_code)
  # 다음 /api/projects/list 호출시 자동으로 load_data() 호출됨
  # 또는 필요시 smart_get()으로 캐시 먼저 확인
