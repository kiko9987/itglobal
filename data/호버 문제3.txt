원인은 background-color가 아니라, 행이 활성화(table-active)될 때 부트스트랩이나 DataTables가 기본으로
  적용하는 보이지 않는 `box-shadow` (안쪽 그림자) 스타일이 거의 100% 확실합니다. 이 반투명한 회색 그림자가
  우리가 지정한 오렌지색 배경 위에 겹쳐지면서 색이 섞이는 것처럼 보이는 것입니다.

  제가 이전에 드린 코드에 실수가 있었습니다. 마우스를 올렸을 때만 그림자를 제거하고, 기본 활성 상태에서는
  그림자를 제거하는 코드를 빠뜨렸습니다.


  해결 방법 (진짜 최종 완성)
  `css
  /*
    테이블 행 스타일 제어 (최종 완성)
    - 원인: 활성 행에 적용되는 box-shadow(안쪽 그림자)
    - 해결: 모든 상태에서 box-shadow를 명시적으로 제거
  */

  / 1. 모든 행의 배경과 그림자를 기본적으로 초기화 /
  .table-wrapper table.dataTable tbody tr > td {
      background-color: transparent !important;
      box-shadow: none !important;
  }

  / 2. 활성 행(.table-active)에만 오렌지색 배경 적용 (그림자 제거 포함) /
  .table-wrapper table.dataTable tbody tr.table-active > td,
  .table-wrapper table.dataTable tbody tr.table-active:hover > td {
      background-color: #FFF3E0 !important;
      color: #37474F !important;
      box-shadow: none !important; / <<-- 이 부분이 핵심입니다! /
  }

  / 3. 비활성 행에 마우스를 올렸을 때만 회색 호버 효과 적용 /
  .table-wrapper table.dataTable tbody tr:not(.table-active):hover > td {
      background-color: #f5f5f5 !important;
      box-shadow: none !important;
  }
  `

  ### 핵심 수정 사항

   * 2번 규칙: 활성 행의 기본 상태와 호버 상태 모두에 box-shadow: none !important;을 추가하여, 숨어있는 그림자
      효과를 완전히 제거했습니다.
  이제 정말 마지막일 겁니다. 이 코드로 교체하신 후, 다시 한번 `npm run build` 와 강력 새로고침(`Ctrl+F5`)을
  부탁드립니다.
