### 1. Race Condition - 캐시 무효화 타이밍 (Critical)

**위치**: `dashboard/services/project_service.py:500-558`

**문제점**:
```python
def invalidate_project_cache(project_code: Optional[str] = None, trigger_refresh: bool = True) -> None:
    # 1️⃣ 무효화 마커 설정
    smart_set_invalidation_marker("current_sheet_data")

    # 2️⃣ 캐시 삭제
    smart_invalidate("current_sheet_data")

    # 3️⃣ 백그라운드 리프레시 스레드 시작
    def background_refresh():
        fresh_data = load_data(force_refresh=True)  # 여기서 race condition 발생 가능
```

**시나리오**:
1. 워커 A가 `invalidate_project_cache()` 호출 → 무효화 마커 설정
2. 워커 B가 동시에 `load_data()` 호출 (lock 획득 후)
3. 워커 B가 오래된 데이터를 Google Sheets에서 가져옴
4. 워커 B가 `smart_set()`으로 오래된 데이터를 캐시에 저장 시도
5. 무효화 마커 검증이 제대로 동작하지 않으면 오래된 데이터가 캐시에 저장됨

**영향도**: 멀티 워커 환경에서 데이터 불일치 발생 가능

**수정 제안**:
```python
# smart_cache_manager.py에서 무효화 마커 검증 강화
def smart_set(key, value, strategy, fetched_at=None):
    # 무효화 마커 확인 (critical)
    marker_key = f"{key}:invalidation_marker"
    marker = redis_client.get(marker_key)

    if marker and fetched_at:
        marker_time = float(marker)
        if fetched_at < marker_time:
            logger.warning(f"오래된 데이터 캐시 저장 차단: {key}")
            return False  # 저장하지 않음
```

### 4. Redis 연결 실패 시 앱 크래시 (Critical)

**위치**: `dashboard/utils/redis_client.py:143-155`

**문제점**:
```python
def __init__(self):
    try:
        self.redis.ping()
        logger.info(f"Redis 연결 성공...")
    except (ConnectionError, TimeoutError, RedisError) as e:
        logger.critical(f"Redis 연결 실패: {e}")
        sys.exit(1)  # 프로세스 종료 ← 문제!
```

**시나리오**:
1. 앱 시작 시 Redis 일시적 장애 (네트워크 지연, 재시작 중)
2. `sys.exit(1)` 호출 → 프로세스 종료
3. Gunicorn/Docker가 재시작 시도
4. Redis 여전히 불안정 → 무한 재시작 루프

**영향도**: 서비스 전체 중단

**수정 제안**:
```python
# Graceful degradation: Redis 없이도 동작하도록
def __init__(self):
    try:
        self.redis.ping()
        self._available = True
    except Exception as e:
        logger.error(f"Redis 연결 실패, 캐시 비활성화: {e}")
        self._available = False
        # 앱은 계속 실행 (캐시 없이)
```

    MAX_FAILURES = 5

            consecutive_failures = 0  # 성공 시 리셋
        except Exception as e:
            consecutive_failures += 1
