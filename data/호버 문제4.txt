다행히, 제가 마지막으로 제안했던 최종 CSS 코드는 두 가지 상황 모두에 대비하여 만들어졌습니다. 즉,
  자바스크립트가 나중에 .table-warning(노란색) 클래스를 추가하든 안 하든, 항상 .table-active의 주황색이 모든
   스타일을 이기도록 설계된 코드입니다.


  따라서 이 코드를 지금 적용하시면, 현재 겪고 계신 '회색 오버레이' 문제가 해결될 뿐만 아니라, 나중에 코드가
  변경되어도 '노란색 배경' 문제가 발생하는 것을 막아주는 완벽한 방지책이 됩니다.

  ### 해결 및 예방을 위한 최종 코드


  dashboard/src/css/main.css 파일의 맨 아래에 아래 코드를 추가하거나, 기존에 추가했던 관련 코드가 있다면 이
  내용으로 완전히 덮어써 주세요.


  `css
  /*
    테이블 행 스타일 제어 (최종 방어 코드)
    - 현재의 '회색 오버레이' 문제와 미래의 '노란색 배경' 문제를 모두 해결
  */

  / 1. 비활성 행의 호버 효과만 처리 /
  .table-wrapper table.dataTable tbody tr:not(.table-active):hover > td {
      background-color: #f5f5f5 !important;
      box-shadow: none !important; / 다른 그림자 효과 방지 /
  }

  /*
    2. 활성 행(.table-active)의 스타일 지정 (가장 중요!)
    - 다른 모든 스타일(줄무늬, 상태 클래스 등)을 덮어쓰고
      항상 이 스타일이 우선적으로 적용되도록 함
  */
  .table-wrapper table.dataTable tbody tr.table-active > td,
  .table-wrapper table.dataTable tbody tr.table-active:hover > td {
      background-color: #FFF3E0 !important; / 연한 오렌지색 /
      color: #37474F !important;
      box-shadow: none !important; / 모든 그림자 효과 제거 /
  }
  `

  ### 적용 방법


   1. 위 CSS 코드를 dashboard/src/css/main.css 파일에 적용하고 저장합니다.
  이 코드를 적용하시면 현재 겪고 계신 문제가 해결되고, 동시에 앞으로 발생할 수 있는 유사한 스타일 충돌
  문제까지 예방할 수 있습니다.
