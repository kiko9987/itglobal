### 1. 커스텀 화살표 제거

  dashboard/src/css/components/project-table.css에서 우리가 직접 정의해 둔 아래 블록들을 제거하거나 주석 처리하세요.

  - /* 3. Sort icon position */ 이하 ::after/content: "\25B2" 등
  - /* 4. Sort icon glyphs */ 블록
  - #projectsTable th[aria-sort="…"]::after { … } 처럼 직접 아이콘을 그리는 부분
  - table.dataTable thead span.dt-column-order { display: none !important; } 같은 숨김 규칙

  이걸 제거해야 DataTables가 기본으로 넣는 span.dt-column-order가 다시 나타납니다.

  ———

  ### 2. 헤더 우측 아이콘 위치 잡기

  기본 아이콘이 레이아웃과 겹치지 않도록 위치만 살짝 다듬습니다. 같은 파일에 다음 스타일을 추가해주세요.

  /* 헤더 텍스트 오른쪽에 아이콘 들어갈 공간 확보 */
  #projectsTable thead th {
    padding-right: 2rem;
  }

  /* DataTables 기본 정렬 아이콘 위치/색상 재정의 */
  table.dataTable thead span.dt-column-order {
    position: absolute;
    right: 0.5rem;
    top: 50%;
    transform: translateY(-50%);
    width: 12px;
    height: 24px;
    display: inline-block;
    pointer-events: none;
  }

  table.dataTable thead span.dt-column-order:before,
  table.dataTable thead span.dt-column-order:after {
    color: var(--gray-500);
    opacity: 0.3;
  }

  /* 정렬 방향 강조 – aria-sort 값에 따라 진하게 */
  #projectsTable thead th[aria-sort="ascending"] span.dt-column-order:before {
    opacity: 1;
    color: var(--primary-color);
  }
  #projectsTable thead th[aria-sort="ascending"] span.dt-column-order:after {
    opacity: 0.15;
  }

  #projectsTable thead th[aria-sort="descending"] span.dt-column-order:after {
    opacity: 1;
    color: var(--primary-color);
  }
  #projectsTable thead th[aria-sort="descending"] span.dt-column-order:before {
    opacity: 0.15;
  }

  이렇게 하면 기본 상태에서는 위·아래 화살표가 모두 연하게 보이고, 정렬하면 해당 방향 화살표만 진하게 강조됩니다.
